# OpenVINO GenAI Workflows

Supported planning profiles include:

- text and chat generation;
- GGUF inference;
- vision-language models;
- embeddings and reranking;
- speech recognition and text-to-speech;
- image generation;
- NPU-specific GenAI prerequisites.

Record model asset, package version, device, generation settings, output type,
and performance metrics. Treat model download, licensing, conversion, and
accuracy evaluation as separate steps.
